# colsam-sport


# Sistema de Monitoreo deportivo Escolar


##Descripcion
Aplicativo web enfocado en la administración y el registro y que ayude a la organización del calendario dé los juegos Inter cursos realizados en la institución.

## Problema Identificado
la mala organización de los inter cursos en el horario en que se juegan los partidos, un mal arbitraje y el poco tiempo q dura el torneo en cualquier deporte.  

## Objetivo General
Desarrollar una plataforma digital que programe, administre e informe sobre los partidos de los intercursos para presentar datos a la comunidad educativa.

## Tecnologías Utilizadas
* HTML5 y CSS3
* Git y GitHub
